Metodología actual

modelo exploratorio, no clínico

1 · Carga teórica del turno

CF = 100 × D × R × (0,45P + 0,35S + 0,20C)
P = carga física, S = sueño/circadiano, C = carga cognitiva, D = duración normalizada, R = recuperación.

2 · Rentabilidad fisiológica

RFP = Ingreso marginal / Carga fisiológica
Cuando faltan tarifas se presenta como parcial. Los valores desconocidos deben ser NA, no 0.

3 · Wearable

Carga = 100 × Σ(wj·xj) / Σ(wj disponibles)
Pesos actuales: pasos 45%, kcal 20%, FC 35%. Los componentes ausentes se reportan por separado.

4 · Aprendizaje personal

Predicción → observación → error → actualización del modelo
Shrinkage hacia priors iniciales, mayor peso de datos recientes y seguimiento de MAE por usuario.

Mejoras metodológicas previstas

Separar exposición laboral de outcome de fatiga y recuperación.
Medición preguardia, postguardia y recuperación a 12–24 h.
Predicciones congeladas antes del turno para validación prospectiva.
Validación temporal y N-of-1 antes de generalizar a modelos poblacionales.
Optimización multiobjetivo: ingreso, carga, sueño, recuperación y preferencias.

Resumen para compartir

TurnoValor es una plataforma de inteligencia laboral para médicos con múltiples empleadores. Integra horarios, ingresos, conflictos, actividad wearable y recuperación para estimar el valor real de cada turno y ayudar al profesional a elegir mejor, no necesariamente a trabajar más. El prototipo actual funciona con FastAPI, PWA, SQLite, Android/Health Connect, generación de PDF y un motor de aprendizaje personal. El siguiente paso es una arquitectura multiusuario segura para un piloto de 20 médicos.
